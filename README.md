### AI Automation & Full-Stack Developer · B.Eng. Mechatronics

I build software that removes manual work — AI agents, retrieval pipelines and API-driven automation.

I started as a mechatronics engineer, programming PLCs and optimising CNC toolpaths. The work was always the same underneath: understand a process, then automate it. Since 2023 I've been doing that in software instead of on the factory floor.

**What I build**

- **AI agents and LLM applications** — autonomous agents, prompt-engineering frameworks and NLP logic that automate data processing and reporting.
- **Retrieval and content pipelines** — ingestion from feeds, APIs and email; clustering, verification against primary sources, and generation.
- **Workflow automation and integrations** — REST and GraphQL APIs, webhooks, OAuth connections and scheduled pipelines linking systems that were never designed to talk to each other.
- **Full-stack and mobile products** — React/Next.js front ends, Python back ends, Flutter apps shipped to Android, Windows, Linux and macOS, on PostgreSQL data layers.

My engineering training shows up in how I write code, not just what I write: layered architecture with enforced module boundaries, automated tests, static type checking and CI from the first commit.

### Selected work

**[AI Media Engine](https://github.com/basltamr31-glitch/AI-Media-Engine)** — *Python · LLM orchestration · retrieval & verification*

An end-to-end content intelligence pipeline. It ingests newsletters, RSS/Atom feeds and JSON APIs (including read-only Gmail OAuth), clusters related stories across sources, verifies claims against primary sources, and generates publication-ready posts for multiple channels in English and Arabic.

Built on a layered architecture (`cli → pipeline → adapters → core`) with machine-enforced import boundaries, plugin discovery via entry points and YAML-configured domain packs. Model providers are swappable — local Ollama models and the Anthropic API behind one interface — with prompt versioning, an append-only provenance ledger and per-run cost accounting. Roughly 1,200 automated tests at an 85% coverage floor, strict `mypy`, `ruff`, and GitHub Actions CI.

**[ERP & Production Management System](https://github.com/basltamr31-glitch/Detergent_ERP_System)** — *Flutter · Dart · offline-first*

A production management system for detergent manufacturing: multi-step form workflows, dynamic tables with automatic calculations, offline-first architecture and PDF export. Full Arabic RTL support. One codebase targeting Android, Windows, Linux, macOS, iOS and web.

**[Claude Dev Skills](https://github.com/basltamr31-glitch/Claude-dev-skills)** — *Open source · MIT*

A curated library of reusable AI-assistant skills for software engineering — Flutter, Android, Supabase, architecture, performance, debugging and AI-assisted development workflows.

**Currently building** — an n8n workflow doing document ingestion and vector retrieval over a private corpus, answering questions through a Telegram bot.
